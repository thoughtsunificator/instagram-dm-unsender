# Translator manual

Translating idmu is currently a bleeding edge effort as there is no precise workflow defined nor there is a whole lot to translate anyway.

There is two main things that are concerned by translation:

1. [idmu's UI](../src/runtime/userscript) itself
2. the [workflow strings](../src/ui/default/strings.js) that are used to automate the process of unsending messages

If you are willing to, you can start by translating [strings](../src/ui/default/strings.js).
